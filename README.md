# hoi4-owb-cheat-mod-house-always-wins

A dedicated cheat mod for the Hearts of Iron IV total conversion **Old World Blues**.

This repository is the source of truth. Deploy mirrors it into the local HOI4 mods folder as `house_always_wins`.

```
python tools/deploy_local_mod.py
```

See [CLAUDE.md](CLAUDE.md) for the local-mod layout and deploy rules.
